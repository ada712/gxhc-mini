# 编译错误解决方案：module 'utils/project.js' is not defined

## ❌ 错误信息

```
页面 【components/project-detail/index]错误:
Error: module 'utils/project.js' is not defined, require args is '../../utils/project.js'
```

## 🔍 问题分析

这个错误是因为编译后的代码中，模块路径引用有问题。虽然文件存在，但小程序运行时无法正确加载模块。

## ✅ 解决方案

### 方案一：清理并重新编译（推荐）

#### 步骤1：清理编译缓存

1. **删除编译目录**：
   ```bash
   # 在项目根目录执行
   rm -rf unpackage/dist/dev/mp-weixin
   ```

   或者在 HBuilderX 中：
   - 右键点击 `unpackage` 目录
   - 选择"删除"（或手动删除 `unpackage/dist/dev/mp-weixin` 目录）

#### 步骤2：重新编译

1. 在 HBuilderX 中：
   - 点击菜单：**运行** → **运行到小程序模拟器** → **微信开发者工具**
   - 等待重新编译完成

2. 或者在微信开发者工具中：
   - 点击 **"编译"** 按钮
   - 或使用快捷键：`Ctrl/Cmd + B`

### 方案二：检查并修复路径引用

#### 检查源代码

确保 `components/project-detail/index.vue` 中的引用是正确的：

```javascript
// 正确的引用方式
import { previewPDF } from '@/utils/project'
```

#### 如果路径有问题，修改为相对路径

如果 `@/` 别名有问题，可以改为相对路径：

```javascript
// 从 components/project-detail/index.vue 到 utils/project.js
import { previewPDF } from '../../utils/project'
```

### 方案三：检查 manifest.json 配置

确保 `manifest.json` 中的路径别名配置正确：

```json
{
  "mp-weixin": {
    "setting": {
      "urlCheck": false
    }
  }
}
```

### 方案四：检查 pages.json 配置

确保 `pages.json` 中没有错误的配置。

## 📝 常见原因

### 1. 编译缓存问题

- **原因**：旧的编译文件可能有问题
- **解决**：删除编译目录，重新编译

### 2. 路径别名问题

- **原因**：`@/` 别名在编译时没有正确解析
- **解决**：检查 HBuilderX 的路径别名配置

### 3. 文件未正确编译

- **原因**：编译过程中断或出错
- **解决**：重新完整编译

### 4. 微信开发者工具缓存

- **原因**：微信开发者工具缓存了旧的编译结果
- **解决**：清除缓存，重新编译
