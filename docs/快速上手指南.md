# 国信合创理事会小程序 - 快速上手指南

## 🎯 5分钟了解项目

这是一个**投资和创业服务平台**，主要服务于：
- **创业者**：可以上传BP（商业计划书）进行AI诊断，发起项目
- **投资人/理事成员**：可以查看项目、评分、管理合同
- **校园合伙人**：可以申请成为校园大使，参与活动，获得经验值
- **管理员**：可以管理用户、添加理事成员、登记积分

---

## 📁 核心目录速览

```
api/              → 所有API接口定义
pages/            → 主包页面（首页、我的、功能页）
subpackage1/      → 核心功能分包（BP诊断、Agent、能量）
campusPages/      → 校园合伙人分包
projectPages/     → 项目相关分包
managePages/      → 管理员功能分包
components/       → 公共组件
store/            → 状态管理（登录、用户信息）
utils/            → 工具函数（请求、缓存）
config/           → 配置文件（API地址、环境）
```

---

## 🔑 关键文件

| 文件 | 作用 |
|------|------|
| `config/app.js` | **API地址配置**，修改这里切换环境（test/mini） |
| `utils/request.js` | **HTTP请求封装**，所有API调用都经过这里 |
| `store/modules/app.js` | **登录状态管理**，Token和用户信息存储 |
| `pages.json` | **路由配置**，所有页面路径在这里定义 |
| `App.vue` | **应用入口**，应用启动时执行 |

## 🔧 常用操作

### 如何添加新页面？

1. 在对应目录创建 `.vue` 文件
2. 在 `pages.json` 的 `pages` 或 `subPackages` 中添加配置
3. 使用 `uni.navigateTo()` 跳转

### 如何调用API？

```javascript
import { getDirectorMember } from "@/api/gxhc.js";

// 调用API
getDirectorMember({ page: 1, limit: 10 }).then(res => {
  console.log(res.data);
});
```

### 如何获取用户信息？

```javascript
// 从Vuex获取
this.$store.state.app.userInfo

// 或调用API获取最新信息
import { getUserInfo } from "@/api/user.js";
getUserInfo().then(res => {
  console.log(res.data);
});
```

### 如何检查登录状态？

```javascript
if (this.$store.state.app.token) {
  // 已登录
} else {
  // 未登录，跳转登录页
  uni.navigateTo({ url: '/pages/mine/login/index' });
}
```

## 📱 页面跳转示例

```javascript
// 普通跳转
uni.navigateTo({
  url: '/pages/project/detail/index?id=123'
});

// TabBar页面跳转
uni.switchTab({
  url: '/pages/home/index/index'
});

// 返回上一页
uni.navigateBack();

// 重定向（关闭当前页）
uni.redirectTo({
  url: '/pages/mine/login/index'
});
```

## ⚠️ 常见问题

### Q: API请求失败？
A: 检查 `config/app.js` 中的API地址是否正确，确认网络连接正常。

### Q: 登录后Token丢失？
A: 检查 `store/modules/app.js` 中的 `LOGIN` mutation是否正确保存Token。

### Q: 分包页面无法访问？
A: 检查 `pages.json` 中的分包配置，确认路径正确。

### Q: 图片不显示？
A: 检查图片路径，确认使用正确的图片URL（云存储或本地路径）。
