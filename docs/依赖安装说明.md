# 依赖安装说明

## ❌ 当前错误

```
[plugin:vite:css] Preprocessor dependency "sass" not found. Did you install it?
```

**原因**：项目使用了 SCSS/SASS 预处理器，但没有安装 `sass` 依赖包。

---

## ✅ 解决方案

### 方法一：使用 npm 安装（推荐）

在项目根目录执行：

```bash
npm install sass --save-dev
```

或者使用 yarn：

```bash
yarn add sass --dev
```

或者使用 pnpm：

```bash
pnpm add sass --dev
```

### 方法二：使用 HBuilderX（最简单）

如果你使用 **HBuilderX** 开发：

1. 打开 HBuilderX
2. 右键点击项目根目录
3. 选择"使用命令行窗口打开所在目录"
4. 执行：`npm install sass --save-dev`

**或者**：

1. 在 HBuilderX 中，点击菜单：工具 → 插件安装
2. 搜索并安装 "npm" 插件
3. 然后在项目根目录右键 → npm → 安装依赖

---

## 📦 完整依赖安装（如果需要）

如果后续遇到其他依赖问题，可以安装完整的 uni-app 开发依赖：

```bash
npm install
```

但通常只需要安装 `sass` 即可解决当前问题。

---

## 🔍 验证安装

安装完成后，检查 `node_modules` 目录下是否有 `sass` 文件夹：

```bash
ls node_modules/sass
```

如果存在，说明安装成功。

---

## 🚀 重新运行项目

安装完 `sass` 后：

1. **如果使用 HBuilderX**：
   - 重新点击"运行" → "运行到小程序模拟器"
   - 错误应该消失了

2. **如果使用 VS Code**：
   - 重新运行：`npm run dev:mp-weixin`
   - 或重启开发服务器

---

## ⚠️ 注意事项

1. **确保已安装 Node.js**：
   - 检查版本：`node -v`（建议 14+）
   - 下载：https://nodejs.org/

2. **如果网络较慢**：
   - 可以使用国内镜像：
     ```bash
     npm config set registry https://registry.npmmirror.com
     ```

3. **如果使用 HBuilderX**：
   - HBuilderX 内置了 Node.js，通常不需要单独安装
   - 但如果命令行执行失败，可能需要配置 Node.js 路径
