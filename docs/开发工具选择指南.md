# 开发工具选择指南

## 🤔 你的疑问

**"用 uni-app 开发还是用微信开发者工具继续开发？"**

## ✅ 正确答案

**两者需要配合使用，不是二选一的关系！**

- **uni-app** = 开发框架（类似 Vue、React）
- **微信开发者工具** = 运行和调试工具（类似浏览器）

它们的关系就像：
- **写代码**：用 uni-app 框架（在 HBuilderX 或 VS Code 中）
- **看效果**：用微信开发者工具（预览和调试）

---

## 🛠️ 推荐开发方式

### 方案一：HBuilderX + 微信开发者工具（推荐新手）

**优点**：
- ✅ 官方推荐，配置简单
- ✅ 一键运行，自动打开微信开发者工具
- ✅ 内置代码提示和语法检查
- ✅ 可视化配置 manifest.json 和 pages.json

**工作流程**：
1. 用 **HBuilderX** 打开项目
2. 点击"运行" → "运行到小程序模拟器" → "微信开发者工具"
3. HBuilderX 自动编译代码并打开微信开发者工具
4. 在微信开发者工具中查看效果和调试

**适用场景**：
- 刚开始接触 uni-app
- 需要快速上手
- 不想配置复杂的开发环境

---

### 方案二：VS Code + 微信开发者工具（推荐有经验开发者）

**优点**：
- ✅ 更强大的代码编辑功能
- ✅ 丰富的插件生态
- ✅ 更好的 Git 集成
- ✅ 更灵活的配置

**工作流程**：
1. 用 **VS Code** 打开项目编写代码
2. 在终端运行编译命令：`npm run dev:mp-weixin`
3. 手动打开微信开发者工具，导入编译后的 `unpackage/dist/dev/mp-weixin` 目录
4. 在微信开发者工具中查看效果和调试

**需要配置**：
- 安装 Node.js
- 安装项目依赖：`npm install`
- 配置 package.json 的 scripts

**适用场景**：
- 熟悉命令行操作
- 需要更灵活的编辑器
- 团队协作开发

## 🎯 我的建议

### 如果你是第一次接触这个项目：

**推荐使用 HBuilderX + 微信开发者工具**

**理由**：
1. ✅ 项目已经是 uni-app 项目，用 HBuilderX 最省事
2. ✅ 不需要额外配置，打开就能运行
3. ✅ 自动编译，修改代码后自动刷新
4. ✅ 官方工具，遇到问题容易找到解决方案

**具体步骤**：
1. 下载安装 [HBuilderX](https://www.dcloud.io/hbuilderx.html)
2. 用 HBuilderX 打开项目文件夹
3. 点击菜单：运行 → 运行到小程序模拟器 → 微信开发者工具
4. 首次运行会提示配置微信开发者工具路径，选择你的微信开发者工具安装目录
5. 之后每次修改代码，HBuilderX 会自动编译并刷新微信开发者工具

---

### 如果你已经熟悉前端开发：

**可以选择 VS Code + 微信开发者工具**

**需要做的准备工作**：

1. **检查是否有 package.json**：
   ```bash
   # 在项目根目录查看
   ls package.json
   ```

2. **如果没有，需要创建**：
   ```json
   {
     "name": "gxhc-mini",
     "version": "1.0.0",
     "scripts": {
       "dev:mp-weixin": "uni build --watch --platform mp-weixin",
       "build:mp-weixin": "uni build --platform mp-weixin"
     },
     "devDependencies": {
       "@dcloudio/vite-plugin-uni": "^3.0.0"
     }
   }
   ```

3. **安装依赖**：
   ```bash
   npm install
   ```

4. **运行开发**：
   ```bash
   npm run dev:mp-weixin
   ```

5. **在微信开发者工具中**：
   - 导入项目
   - 选择目录：`unpackage/dist/dev/mp-weixin`

## ⚠️ 重要说明

### 不要直接用微信开发者工具开发原生小程序代码！

**原因**：
1. ❌ 这个项目是 uni-app 项目，不是原生小程序
2. ❌ 如果用微信开发者工具直接写原生代码，会破坏项目结构
3. ❌ uni-app 的语法和原生小程序不同（如：`<view>` vs `<div>`）
4. ❌ 无法享受 uni-app 的跨平台优势

**正确理解**：
- uni-app 是**开发框架**（写代码用的）
- 微信开发者工具是**调试工具**（看效果用的）
- 它们**必须配合使用**

## 🚀 快速开始（推荐方式）

### 第一步：安装工具

1. **下载 HBuilderX**：
   - 访问：https://www.dcloud.io/hbuilderx.html
   - 下载标准版（免费）

2. **安装微信开发者工具**：
   - 访问：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 第二步：打开项目

1. 打开 HBuilderX
2. 文件 → 打开目录 → 选择项目文件夹

### 第三步：配置微信开发者工具路径

1. 工具 → 设置 → 运行配置
2. 配置"微信开发者工具路径"（选择微信开发者工具的安装目录）

### 第四步：运行项目

1. 点击顶部菜单：运行 → 运行到小程序模拟器 → 微信开发者工具
2. 首次运行会提示登录微信开发者工具，扫码登录即可
3. 之后每次修改代码，会自动编译并刷新

## ❓ 常见问题

### Q: 可以直接用微信开发者工具写代码吗？
A: **不可以**。这个项目是 uni-app 项目，必须用 uni-app 的方式开发。微信开发者工具只用于预览和调试。

### Q: 可以用其他编辑器吗？
A: 可以，但需要手动配置编译。推荐 HBuilderX 或 VS Code。

### Q: 修改代码后没有自动刷新？
A: 
- HBuilderX：检查是否开启了"保存时自动编译"
- VS Code：需要手动运行编译命令或配置自动编译

### Q: 微信开发者工具报错？
A: 
- 检查是否选择了正确的项目目录（应该是编译后的目录）
- 检查微信开发者工具的基础库版本
- 查看控制台错误信息
